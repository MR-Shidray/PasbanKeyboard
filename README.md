# PasbanKeyboard (بدون Android Studio)

این پروژه یک کیبورد بسیار ساده (IME) برای اندروید است که بعد از زدن «فاصله»،
۱ تا ۴ واژه‌ی آخر را با دیتابیس `pasban.db` تطبیق می‌دهد و اگر معادل پارسی پیدا کند،
در نوار پیشنهادها نمایش می‌دهد.

## خروجی APK بدون اندروید استودیو (پیشنهادی: GitHub Actions)
1) یک ریپوی جدید در GitHub بسازید.
2) محتویات این پوشه را داخل ریپو کپی کنید و push کنید.
3) بروید به تب **Actions** → Workflow به نام **Build APK** را اجرا کنید (یا با push خودش اجرا می‌شود).
4) بعد از اتمام، از بخش **Artifacts** فایل `pasban-debug-apk` را دانلود کنید. داخلش `app-debug.apk` است.

## نصب و فعال‌سازی کیبورد
- APK را نصب کنید.
- Settings → System → Languages & input → On-screen keyboard → Manage keyboards
  کیبورد «پاسبان» را فعال کنید و انتخابش کنید.

## نکته‌ها
- این MVP است: layout کیبورد ساده است و برای تولید واقعی باید بهتر شود.
- اگر خواستید «پیشنهاد حین تایپ» یا «تشخیص پیشوندی» اضافه کنید، باید lookup را توسعه بدهید.
